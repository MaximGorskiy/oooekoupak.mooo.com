# oooekoupak.mooo.com

Статический сайт компании **VIRIDI GROUP** (ИП Голубинова Н.В., Нижний Новгород) —
профессиональная и бытовая химия, косметика и наборы для отелей, товары для уборки.

Сайт собран из материалов сообщества ВКонтакте [vk.ru/viridi_goodhim](https://vk.ru/viridi_goodhim)
(посты, фотографии и видео), сохранённых локально 2026-11-23.

## Структура

```
index.html            одностраничный сайт (вся разметка)
assets/css/style.css  стили и адаптив
assets/js/main.js     меню, лайтбокс, видео-плееры, появление блоков
assets/img/           фотографии (оптимизированы до ~1600 px)
assets/poster/        превью видео
assets/video/         видео mp4 (H.264/AAC, до 720p, faststart)
```

Хостинг: GitHub Pages, ветка `main`, корень репозитория.

## Локальный просмотр

```bash
cd oooekoupak.mooo.com
python -m http.server 8801
# открыть http://127.0.0.1:8801/
```

## Обновление материалов

Исходные файлы (оригинального разрешения) лежат в соседней папке архива:
`../media/photos/`, `../media/videos/`. Перед заменой на сайте ужать их
(например, через ffmpeg / любой конвертер) и класть результат в `assets/`.
